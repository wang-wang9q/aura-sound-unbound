# AURA / 01 — Sound. Unbound.

Original portable speaker concept website. Static HTML, CSS and JavaScript with locally bundled images, font and animation scripts.

Includes scroll animation, three original synthesized soundscapes, product hotspots, color selection, browser-local preferences, and downloadable inspiration cards. No account, payment or external API is required to use the website.

The product, price and specifications are concept design content. Product and lifestyle images were generated specifically for AURA with OpenAI imagegen. Soundscapes are original browser synthesis. Manrope is licensed under the SIL Open Font License (included in assets/Manrope-OFL.txt). GSAP license information is included in the distributed scripts.

This is the public static hosting copy of the AURA website.
